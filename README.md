# Golden State Warriors 2026/27 — сайт для болельщиков

**Сайт: https://ijpteb.github.io/gsw-portal/**

Неофициальный сайт о «Голден Стэйт Уорриорз» в сезоне НБА 2026/27. Он не связан с НБА, клубом или ESPN.
На сайте есть:

- расписание и счёт, в том числе идущего матча;
- состав и подробная карточка каждого игрока;
- статистика и лидеры команды;
- таблица Западной конференции;
- сравнение двух игроков;
- новости;
- история клуба;
- избранные игроки.

Все данные берутся из бесплатных открытых источников. У каждого блока подписано, откуда данные и когда они обновлены.
Если данных нет, вместо цифр стоит прочерк с причиной. Демо-данных и цифр «для примера» на сайте нет.
Логотипы и фото взяты с официальных серверов ESPN и НБА, права на них принадлежат владельцам.

## Как открыть

**Обычно ничего запускать не нужно**: откройте ссылку выше. Данные обновляются сами, на серверах GitHub:

| Что | Как часто |
|---|---|
| Счёт идущего матча | раз в минуту |
| Расписание в день матча | раз в 5 минут |
| Таблица, статистика, состав, травмы | раз в час |
| Новости | раз в 20 минут |

Кнопка «Обновить» в шапке сразу подгружает самые свежие опубликованные данные.

### Запуск на своём компьютере одним действием

**Mac.** Дважды щёлкните файл **`Запустить сайт.command`** в папке проекта. Он скачает свежие данные (1–3 минуты) и откроет сайт в браузере по адресу http://localhost:8765. Чтобы остановить сайт, закройте окно Терминала.

- Если macOS не открывает файл и пишет про неустановленного разработчика, откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть». В старых версиях macOS: правый щелчок по файлу → «Открыть». Это нужно сделать один раз.
- При первом запуске macOS может предложить установить «инструменты разработчика командной строки»: согласитесь. В них есть Python, которым работает сборщик.

**Любая система, одна команда.** Нужен Python 3.9 или новее (https://www.python.org). Выполните в папке проекта:

```bash
python3 -m collector run && python3 scripts/dev_server.py
```

Затем откройте http://localhost:8765. Остановить сайт: Ctrl+C. На Windows вместо `python3` пишите `py` (на Windows мы не проверяли).

Устанавливать ничего, кроме Python, не нужно: у проекта нет сторонних библиотек.

## Откуда данные

| Данные | Источник |
|---|---|
| Расписание, счёт, идущий матч | ESPN |
| Состав, травмы, статистика игроков и команды, места команды в лиге | ESPN |
| Таблица Запада | ESPN |
| Новости на английском | ESPN и блог болельщиков Golden State of Mind |
| Новости на русском | «Спорт-Экспресс», только новости о «Голден Стэйт» |
| Фото игроков и логотипы | ESPN (копии хранятся у сайта); нет фото — заглушка с номером и инициалами |
| История клуба | NBA.com и сайт клуба (nba.com/warriors); ссылки — на странице «История» |

ESPN отдаёт данные через открытые, но не описанные официально адреса. Он может изменить их без предупреждения — что делать тогда, написано ниже.

Чего нет и почему:

- **Данные NBA.com закрыты для программ.** Сайт НБА отвечает отказом (403) или не отвечает. Обходить защиту нельзя, поэтому сборщик NBA.com не использует. По статьям NBA.com сверяли «Историю» и данные ESPN.
- **Запасного бесплатного источника расписания и счёта нет.** Если ESPN перестанет отвечать, сайт покажет последние сохранённые данные с их датой.
- **balldontlie и Highlightly работают только с ключом.** Ключ можно получить самому (см. ниже).
- **Basketball Reference не пускает программы**: показывает проверку «я не робот». Историю сверяли по NBA.com и сайту клуба.
- **Имена игроков — латиницей**, как у ESPN. Поиск понимает и русское написание, например «Карри» или «Подземски».
- **Новости — только краткое описание из ленты.** Полный текст открывается кнопкой «Читать в источнике».

## Как это устроено

- **Сборщик** (`collector/`, Python, только стандартная библиотека) скачивает данные и сохраняет их в файлы JSON. На GitHub его запускает задача **«Сбор данных»** (Actions). Она работает без перерыва: раз в минуту проверяет, что пора обновить. Обновлённые данные она сохраняет в ветку `data` репозитория.
- **«Публикация сайта»** выкладывает сайт на GitHub Pages, когда данные изменились.
- **Если источник не ответил, прежние данные остаются.** На сайте у них появляется пометка «Источник временно недоступен — показаны данные от …». Нули вместо данных сайт не рисует.
- **Служебная страница «Состояние данных»**: https://ijpteb.github.io/gsw-portal/#/status (также в меню «Ещё»). Там видно по каждому набору данных, когда он обновлялся, когда была последняя попытка и какая была ошибка.

## Что делать, если источник перестал работать

Срочно ничего делать не нужно: сайт продолжит показывать последние сохранённые данные с их датой.
Чтобы починить, идите по шагам:

1. **Посмотрите «Состояние данных»** (`#/status`). Там видно, какие данные не обновляются и с какой ошибкой.
2. **Проверьте, работает ли сам GitHub**.
   - Откройте вкладку **Actions** репозитория → **«Сбор данных»**. Последний запуск должен быть «в работе» (жёлтый значок).
   - Если GitHub сбоит (https://www.githubstatus.com), подождите: после восстановления сбор продолжится сам.
   - Чтобы запустить сбор сразу: **«Сбор данных» → Run workflow**. Можно отметить «Обновить всё прямо сейчас».
3. **Если GitHub в порядке, а источник отвечает ошибкой** (например, ESPN поменял адрес или формат), проверьте источники.
   - На своём компьютере:
     ```bash
     python3 tests/check_sources.py
     ```
     Скрипт покажет, какой адрес не отвечает или какие данные не удалось разобрать.
   - С серверов GitHub: **Actions → «Проверка источников» → Run workflow**. Ответы источников сохранятся в файл `probe-responses` у запуска.
4. **Почините разбор этого источника.**
   - Код каждого источника — в одном файле: `collector/sources/espn.py` или `collector/sources/rss.py`.
   - Свежие ответы источников сохраняет `python3 tests/check_sources.py --save`, в папку `tests/fixtures/new/`. Положите их вместо старых в `tests/fixtures/` и обновите ожидаемые числа в тестах.
   - Запустите тесты:
     ```bash
     python3 -m unittest discover -s tests -t .
     ```
   - После исправления отправьте код в репозиторий и запустите «Сбор данных» вручную: дежурство перейдёт на новый код в течение минуты.
5. **Запасной источник расписания и счёта (balldontlie) требует ключа.**
   - Получите ключ сами на сайте balldontlie.
   - Добавьте его в репозиторий: **Settings → Secrets and variables → Actions → New repository secret**, имя `BALLDONTLIE_API_KEY`. Ключ хранится только на сервере и в браузер не попадает.
   - Сам код подключения этого источника ещё не написан.

Проверить, как сайт переживает отказ источника, можно на своём компьютере:

```bash
GSW_BLOCK_HOSTS=espn python3 -m collector run --force
```

Эта команда отключает ESPN на время одного запуска. После неё на страницах появится пометка «Источник временно недоступен — показаны данные от …», а данные останутся прежними.
Вернуть всё как было: `python3 -m collector run --force`.

## Что делать в течение сезона

- **Ничего, если всё работает.**
  - Два матча Кубка НБА, которых пока нет в календаре ESPN, сайт подхватит сам, когда ESPN их добавит (ожидается после 4–10 декабря).
  - Плей-ин и плей-офф сборщик ищет с 15 марта 2027 года.
- **Раз в неделю задача «Поддержка расписания»** делает служебную запись в репозиторий. Без активности GitHub отключает задачи по расписанию через 60 дней. Если он всё же их отключил: Actions → «Сбор данных» → Enable workflow.
- **«История» правится вручную**, файл `site/js/history-data.js`. Если, например, Стефен Карри обновит рекорд, поправьте цифру, дату проверки `CHECKED` и сверьте рекорд по источнику.
- **Новый сезон (2027/28)**:
  - поменяйте сезон и даты в `collector/config.py`;
  - замените подписи «2026/27» в файлах `site/`;
  - проверьте источники командой `python3 tests/check_sources.py`.

## Для разработчика

| Папка или файл | Что внутри |
|---|---|
| `collector/` | сборщик данных |
| `site/` | сайт: HTML, CSS и JS без сборки и сторонних библиотек |
| `scripts/` | вспомогательные скрипты для GitHub и локальный сервер |
| `tests/` | автотесты на настоящих сохранённых ответах источников |
| `.github/workflows/` | задачи GitHub Actions |

- Тесты: `python3 -m unittest discover -s tests -t .`
